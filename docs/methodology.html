Methodology & data sources

What this is

An open-source aggregation of publicly reported information about new and upcoming residential real estate projects in the Chennai Metropolitan Area. Data is researched with AI-assisted web research (Claude), stored as plain JSON in the GitHub repository, and refreshed on demand — every refresh is a reviewable git commit.

It is a shortlisting and research tool, not investment advice. Prices, dates, and RERA details change; always verify on the official TN RERA portal and with the developer before any transaction.

Upside Score (0–100)

A transparent, rule-based composite. Each project's per-factor breakdown is stored in the data and shown in the UI — no black box. Weights:

FactorWeightWhat scores high
Entry stage25Pre-launch and just-registered projects (earliest entry, largest pricing headroom); near-possession scores lowest.
Infrastructure proximity20Close to upcoming Metro Phase 2 stations, Peripheral Ring Road interchanges, the proposed Parandur airport, or major employment hubs.
Locality momentum20Micro-market with rising prices, strong absorption, and multiple demand drivers.
Relative pricing15Launch price at or below the locality's prevailing band.
Developer track record10Established delivery history at scale; unknown or troubled developers score low.
Rental yield potential10Locality rental yields near or above ~4%.

Score bands used across the site: 75+ highest upside · 60–74 · 45–59 · <45.

A high Upside Score is not a recommendation — it means the rule set found more upside signals. Read it together with the Risk flag.

Risk flag

Low / Medium / High, considering: RERA registration status (unregistered pre-launches are automatically riskier — booking before registration is also legally restricted), developer history (delays, litigation), flood-zone exposure (Pallikaranai, Perumbakkam, parts of Velachery, Mudichur/Tambaram and low-lying OMR stretches are historically flood-prone), and micro-market oversupply.

Categories: Early Entrant (pre-launch/new launch), High Upside (score ≥ 78), Steady/Rental (yield-led), Premium (upper price band), Plotted/Land, Watchlist/Risky (high risk flag).

Data confidence levels

verified — sourced from the official TN RERA portal (rera.tn.gov.in).
reported — from news coverage, property portals (Magicbricks, Housing.com, 99acres, Squareyards…), or developer announcements; RERA details not independently confirmed on the portal.
estimated — inferred (e.g., price band from locality norms); treat as indicative only.

The TN RERA portal frequently blocks automated access; when it does, records are built from secondary sources and marked accordingly. RERA numbers are shown only when actually found in a source — they are never inferred. Coordinates are locality-level approximations unless marked exact.

Refresh workflow

The repository contains a CLAUDE.md contract: opening a Claude Code session in the repo and typing refresh re-runs the research, updates the JSON data files, re-scores everything, and pushes a commit — GitHub Pages redeploys automatically. deep refresh re-verifies every record; refresh <locality> updates one micro-market. The meta.json change-log records what changed in each refresh.

Scoring is computed deterministically by scripts/score.py from the raw fields, so a re-run with unchanged inputs produces unchanged scores.
